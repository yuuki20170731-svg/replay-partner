# 就活での説明に使うメモ

短い作品紹介: 「リプレイ・パートナー」は過去の自分の行動を記録・再生し、分身と協力して仕掛けを解くブラウザ用パズルです。固定時間刻みの判定と、色以外でも状態を伝えるUIを工夫しました。

制作意図: 操作が理解できることと、失敗しても試し直せることを大切にした。技術上の課題は、複数の分身と箱・扉の操作順序。解決方法は、同じ移動関数で全員を処理し、古い分身から順に扉を更新すること。全10ステージの解法を自動テストに残し、ルール変更が解法を壊したら検出できる。

面接で示す順序: ①ステージ2で一人では通れない扉を見せる ②行動を記録 ③分身がスイッチを踏み、現在の自分が通る ④判定コードとテストを説明 ⑤表示・アクセシビリティ上の配慮と限界を話す。

AIの利用: Codexが実装、文章、検証の支援に参加。本人がどの部分を設計・修正・説明できるかは、本人の確認を経て記載する。本人だけで全実装したとは説明しない。

今後: 第三者テストと難易度調整、途中記録の保存、Canvas操作のアクセシビリティ改善。公開URL・GitHub URL・開発期間・ユーザー数は実在するものだけ記載する。

60〜90秒動画案（未撮影）: 一文紹介→閉じた扉→記録→分身のスイッチ→脱出→二体と箱→実在するリンク。録画後に内容と秒数を実測する。
