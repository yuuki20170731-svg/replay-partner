# 実装構成

`src/engine/stages.ts` は盤面データ、`simulation.ts` は移動・記録・再生・扉の判定、`storage.ts` は保存。`src/game/BoardScene.ts` はPhaser描画、`src/game/main.ts` は画面と入力。`src/site.ts` は紹介ページ。

シミュレーション状態は `replay / recording / cleared`。記録開始時は部屋をリセットし、既存分身の再生を開始。確定時は行動列を追加し、再度リセットする。リトライは分身を保持、削除は最後の分身だけ、全初期化はすべて消す。

各刻みの順序: 扉更新→古い順の分身行動と都度扉更新→現在の自分の行動→扉更新→クリア判定。箱の競合は先に処理した行動が優先。閉じかけた扉を占有していれば開いたまま。失敗した移動も記録され、再生時は当時の固定座標へ強制移動しない。

記録データは `Command[][]`。一体ごとに最大150コマンド、刻み200ms。再生終了後は位置を保持。保存するのは進行と設定のみで、途中の記録はブラウザ更新で消える。この制約はプレイヤーへ明示する改善候補。

判定をPhaserから分離したのは、全ステージの実解法をNode上で高速に検証するため。バックエンドやユーザー登録は不要。紹介ページとゲームをViteの別入口に分け、紹介ページの初回読込を軽くした。
