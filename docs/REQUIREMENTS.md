# 仕様と完成条件

目的: 「過去の自分の行動が今の自分を助ける」体験を、初見でも理解できる固定画面パズルで伝える。対象はPCブラウザで遊ぶ人と、制作物を確認する採用担当者。

MVPは移動、スイッチ、扉、分身1体、記録と再生、3ステージ、リトライ。完成版は分身2体、箱、全10ステージ、ヒント、保存、設定、紹介ページ、検証資料。オンライン対戦、ランキングサーバー、戦闘、装備、ステージエディタは対象外。

200msの固定刻みで記録する行動は上下左右と待機。記録確定時、人物・箱・扉・スイッチを初期状態に戻し、全分身を時刻0から再生。分身は再生終了後にその場で待機する。キャラクター同士は重なれる。箱は壁、閉じた扉、他の箱を通れない。記録中に出口へ着いてもクリアにならない。現在の自分が再生中に出口へ着いたときだけクリア。

閉じる扉に人物または箱がいる間は開いたまま。古い分身から順に動き、各行動後に扉を更新し、現在の自分が最後に動く。同じ箱を同時に押す場合、この順序で先に成功した操作が盤面を更新する。阻まれた分身はその刻みの移動を失い、次の行動へ進む。上限の150刻みで自動確定。

クリア状況、音量、ミュート、演出設定はlocalStorageに保存。互換性のないデータでは初期値に戻す。保存できなくてもプレイ可能。

完成条件は `docs/VERIFICATION.md` に実施結果を記録する。公開の完成条件は別で、実際のGitHubリポジトリ、CI、Cloudflare URLでの動作確認が必要。
