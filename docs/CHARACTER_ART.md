# キャラクター画像 RC5

更新 RC6：現在使用する画像は `unity/Assets/Resources/explorer-walk-v2.png`。組込み画像生成で既存の探索者を参照し、同じ解剖学的右手にランタンを固定した正面／背面各4コマ、4列×2行、透過背景のシートへ変更。指示は「人物・衣装・視点の統一、足の動きだけを変え、背面では顔を見せない」。ランタンの持ち手は揃いましたが、生成による微小な輪郭・位置差は残ります。上下移動で行を切り替え、左右移動は反転です。以下はRC5時点の履歴。

保存先：`unity/Assets/Resources/explorer-walk-v1.png`。組込み画像生成ツールを使用し、透過PNGのままプロジェクトへコピー。旧パーツ描画は画像が読み込めない場合のフォールバックとして保持。

生成指示の要点：オリジナルの手描き風ダンジョン探索者。深い青緑のフードとマント、使い込んだ革装備、真鍮の留め具、ブーツ、暖色ランタン。背景透過、文字・武器なし。2×2の同寸セル、同じ人物・視点・大きさで待機と歩行の4コマ。

4コマは画像のセルをUnityのSpriteとして参照し、移動量に応じて切り替える。静止画の揺れだけではなく歩行の絵を変更する方式。分身は同じ画像を青く着色。生成画像の各コマの持ち手・姿勢は完全に同一ではなく、厳密な多方向スプライトや骨格アニメーションではない。

改善案は [次の改善候補](NEXT_IMPROVEMENTS.md) を参照。
