# 次に検討したい改善

キャラ改良RC5は生成した透過イラストを使う探索者。布のフード・使い込んだ革装備・暖色ランタンで迷宮の床／壁に合わせた画風。待機と歩行3コマを切り替える簡易アニメーション。武器や装備性能は追加しておらず、パズルのルールは変更しない。

## 見た目の改善候補

- キャラの上下移動に応じた背面／正面の絵。現状は同じ斜め正面の絵を左右反転するため、方向表現は限定的。
- 歩行コマの位置・持ち手・輪郭の統一。生成した4コマはラフな動きで、ランタンの位置と腕の形が揺れる。完成度を上げるには再生成／専門的な素材調整と目視確認が必要。
- 鍵・門・箱の画風と光源の統一。主人公だけを高精細にすると盤面との密度差が出るため、小さい表示での輪郭と読みやすさを優先する。
- 足元の円は選択を示す補助として残すが、主張を抑える。分身は番号と青色で区別し、色だけに依存しない。

優先度順の追加候補（未実装）：

1. 調べられる石碑・囚人の手記：任意で読める短い文章に、主人公が戻りたい理由や分身の正体を散りばめる。必須の長い会話で再挑戦を止めない。
2. 段階式ヒント：最初は注目すべき仕掛け、次は役割分担、最後は具体的な手順。答えをすぐ表示せず考える余地を残す。
3. フィードバックのテーマ別効果音：水路の足音や門の石音など。音量設定・無音時の視覚情報を維持し、素材の権利を確認する。
4. クリア済み部屋の任意チャレンジ：分身数・再挑戦回数を目標に再プレイ。通常の脱出は採点で妨げない。

敵との戦闘・装備育成・大量の部屋の追加は、時間差協力パズルの焦点と検証量を広げるため今は見送る。これら追加より先に全10部屋の通常操作の通しプレイが必要。
